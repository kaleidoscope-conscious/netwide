# Code of Conduct

## Our pledge

We want participation in Netwide to be a harassment-free experience for everyone, regardless
of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender
identity and expression, level of experience, education, socio-economic status, nationality,
personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be kind and patient. Everyone was new once.
- Assume good faith; ask before assuming otherwise.
- Accept constructive criticism gracefully — and give it kindly.
- Focus on what is best for the community and for people running this on their own networks.
- Respect privacy. **Never post screenshots, logs, or evidence bundles containing someone
  else's network.** This project is built on a "your network is yours" principle — extend it
  to each other.

## Unacceptable behaviour

Harassment, personal attacks, sexualised language, publishing others' private information,
deliberate disruption, and any other conduct that would reasonably be considered inappropriate
in a professional setting.

## Scope

This applies in all project spaces — issues, discussions, PRs, commits, code comments, release
notes — and when representing the project publicly.

## Enforcement

Report to the maintainers via a private security advisory or by opening an issue and asking
for a private contact. Reports are reviewed promptly and handled confidentially.

Maintainers who do not follow or enforce this code in good faith may face temporary or
permanent repercussions.
