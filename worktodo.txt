3. PROBING / DETECTION ENGINE FLAWS (probers.py, wireless.py, fingerprint.py, oui.py)
--------------------------------------------------------------------------------

[3.1] 10-Stage De-Cloaker logic bugs (wireless.py)

  - CRITICAL: parse_iw_scan_dump() cannot parse real `iw` BSS output
    (wireless.py:58-64): block split on "^BSS " then `first_line.split("(")[0]`
    yields e.g. "BSS 00:11:22:33:44:55 on freq 2437" -> length check fails -> every
    AP skipped -> entire de-cloaker fed an EMPTY AP list (silent false negatives
    by design of the parser).
  - CRITICAL: Stage 3 verdict precedence bug (wireless.py:736-737):
    `f"VERIFIED_WPS_SOFTAP ({wps_name}" + (f" on '{parent_router}')" if parent_router else ")")`
    parses as `(A+B) if C else D` -> when parent_router falsy verdict becomes ")".
    Even when truthy, missing closing paren.
  - Stage 7/8 hidden-VAP unmask builds malformed MAC (wireless.py:842-847):
    `bssid[3:8]` is a character slice, not octet group -> unmasked_prefix invalid ->
    OUI unmask branches (Amazon/TCL/Sony/etc.) unreachable.
  - MAC comparisons use fragile char-offset slicing (wireless.py:745-771):
    bssid[:5], bssid[3:8], bssid[12:], vb[6:] etc. mix conventions -> false
    positives/negatives.
  - Stage 10 co-location accepts raw RSSI delta <= 3 dB OR Pearson r>=0.85
    (wireless.py:806-817) -> weak multipath evidence, false-positive risk.
  - nmcli SIGNAL field misread: treated as 0-100 percent, actually dBm
    (wireless.py:265-292) -> bogus signal math on nmcli-sourced APs.
  - Unvalidated BSSID before int() conversion (wireless.py:205-206, 748) ->
    crash risk on malformed nmcli/iw values.
  - Rogue-RA lladdr[:14] bogus slice (wireless.py:2887).

[3.2] Protocol auditor logic bugs (probers.py, fingerprint.py)

  - CRITICAL: MQTT CONNACK parsing reads wrong byte (probers.py:2241-2243):
    return code at resp[2] (byte 0 = packet type 0x20, byte 1 = flags, byte 2 = RC);
    code reads resp[3] and requires len>=4 -> anonymous-allowed brokers reported
    as not anonymous -> CRITICAL "Unauthenticated Anonymous MQTT" finding can never fire.
  - SMB2 negotiate: never offers SMB 3.1.1 dialect (0x0311) (probers.py:2095-2129, 2205-2206);
    single recv(4096) on TCP -> partial-frame risk -> parser failures.
  - fingerprint.py:838-839: SMB signing finding reads `security_mode` which is never
    populated by the SMB parser -> always default 0x00.
  - Key mismatches between probers and synthesizer cause systematic false negatives:
    Ollama (probers.py:2315 `ollama_ai` vs fingerprint.py:588 `ollama`),
    Sonos (probers.py:2284 camelCase vs fingerprint.py:558-559 snake_case),
    Hue (probers.py:2298-2304 vs fingerprint.py:574-575),
    MQTT (probers.py:2244-2250 vs fingerprint.py:1089-1090).
  - TTL-based OS inference (fingerprint.py:286-292) and default confidence 35
    (fingerprint.py:170-180) with single-signal-only increments -> weak heuristics.

[3.3] Reliability / hang / silent-failure flaws (probers.py, wireless.py, fingerprint.py)

  - ~92 broad `except Exception: pass` clauses in probers.py (e.g. 55-56, 321-322,
    449-450, 559-574); whole nmcli scan wrapped in except (wireless.py:230-347);
